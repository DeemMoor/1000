# Тысяча (1000)

Карточная игра «Тысяча» для Android, iOS, Web, Windows, macOS и Linux.
Играть можно против компьютера или онлайн с людьми.

## Структура проекта

```
1000/
  pubspec.yaml        — pub workspace
  packages/engine/    — thousand_engine: правила игры на чистом Dart (общие для клиента и сервера)
  app/                — Flutter-клиент
  server/             — thousand_server: сервер для мультиплеера (Dart, WebSocket)
```

Все правила, которые можно менять, собраны в `GameRules` (`packages/engine/lib/src/rules.dart`).
В тексте ниже такие настройки помечены *(настройка)*.

## Разработка

```bash
export PATH="$HOME/development/flutter/bin:$PATH"
flutter pub get                      # зависимости для всего workspace
(cd packages/engine && dart test)    # тесты движка
(cd app && flutter run -d chrome)    # запуск клиента в браузере
dart run server/bin/server.dart      # запуск сервера
```

# Правила игры

## Игроки и колода

- Играют **трое**.
- В колоде **24 карты**: 9, 10, В, Д, К, Т в каждой из четырёх мастей.
- Карты по старшинству: **9 < В < Д < К < 10 < Т**.

| Карта  | Очки |
|--------|------|
| Туз    | 11   |
| Десять | 10   |
| Король | 4    |
| Дама   | 3    |
| Валет  | 2    |
| Девять | 0    |

Все карты колоды вместе стоят **120 очков**.

## Марьяжи

Марьяж — это король и дама одной масти на руке у одного игрока.

| Масть  | Очки |
|--------|------|
| ♥ Черви | 100 |
| ♦ Бубны | 80  |
| ♣ Трефы | 60  |
| ♠ Пики  | 40  |

**Тузовый марьяж** — все четыре туза на руке, **200 очков**. По умолчанию выключен *(настройка)*.

## Раздача

- Сдатчик меняется каждый кон по кругу.
- Каждый игрок получает **7 карт**, ещё **3 карты** уходят в **прикуп**.
- **Пересдача** делается, если:
  - в прикупе **меньше 5 очков** *(настройка)*;
  - у кого-то из игроков на руке **все четыре девятки** *(настройка)*.

## Торговля

- Торговлю начинает игрок слева от сдатчика. Он обязан заказать минимум **100**.
- Дальше игроки по кругу либо повышают заказ с шагом **5** *(настройка)*, либо пасуют.
- Спасовавший в этом коне больше не торгуется.
- Заказать **больше 120** можно, только если на руке есть марьяж (или тузовый марьяж, когда он включён).
  Предел заказа — 120 плюс стоимость всех марьяжей на руке: с червовым можно до 220, с червовым и пиковым — до 260.
- Торговля заканчивается, когда остаётся один игрок. Он становится **заказчиком**.

## Прикуп

- Заказчик открывает прикуп всем игрокам и забирает его себе.
- Потом он отдаёт **по одной карте** каждому сопернику, чтобы у всех снова было по 7 карт.
- После этого заказчик может **повысить** заказ (понизить нельзя) или **расписаться** (см. ниже).

## Розыгрыш

- Первым ходит заказчик.
- Надо класть карту **в масть**. Если масти нет, надо бить **козырем**. Если нет и козыря, можно положить любую карту.
- Перебивать старшей картой не обязательно.
- Взятку забирает старший козырь, а если козырей во взятке нет — старшая карта масти, с которой зашли.
- Взявший взятку ходит следующим.

### Объявление марьяжа

- Объявить марьяж можно только **своим ходом**, если у тебя на руке есть король и дама этой масти.
- Перед этим нужно взять **хотя бы одну взятку**. Исключение — заказчик на самом первом ходу кона: в этот момент он объявить марьяж не может.
- Объявляя, игрок ходит королём или дамой марьяжа. Очки марьяжа идут ему.
- Масть объявленного марьяжа становится **козырем** до следующего объявления.
- Тузовый марьяж объявляется ходом туза. Он даёт 200 очков, но козырь не меняет.

## Подсчёт очков за кон

- Набрал заказчик свой заказ (взятки плюс марьяжи) — ему записывается **заказ**. Не набрал — заказ **вычитается**.
- Соперники записывают свои очки (взятки плюс марьяжи), **округлённые до 5** *(настройка)*: 32 → 30, 33 → 35.

## Роспись

- Посмотрев прикуп, заказчик может отказаться играть кон, то есть **расписаться**.
- Тогда у заказчика вычитается заказ, **выигранный на торговле** (повышение после прикупа не учитывается).
- Каждому сопернику записывается **половина этого заказа, округлённая вниз до 5**: 105 → по 50, 110 → по 55, 115 → по 55.
  Особенно приятно, когда у соседа 505 — он улетает прямо в яму.
- За **три росписи** — штраф **−120** *(настройка)*.

## Болт

- **Болт** — кон, в котором игрок не взял ни одной взятки.
- За **три болта** — штраф **−120** *(настройка)*.
- Болты и росписи считаются за всю партию, не обязательно подряд. После штрафа счётчик обнуляется.

## Бочка

- Игрок, набравший **880 очков** *(настройка)*, «садится на бочку».
- На бочке очки за взятки ему не записываются. Чтобы выйти, нужно стать заказчиком и сыграть заказ.
- На это даётся **3 попытки** *(настройка)*. Не вышло — **−120**, и игрок «слетает» с бочки.

## Яма

- Если счёт игрока после кона оказался **ровно 555**, он сбрасывается **в 0** *(настройка)*.

## Победа

- Побеждает игрок, который первым набрал **1000 очков** *(настройка)*.
